## 关于我

```txt
方向    : macOS 小工具 · Electron 桌面应用 · 静态站
偏好    : 安静、实用、清晰、能真实解决一点小问题
方式    : 先能跑，再顺手，再好看一点
```

- **先做真实链路**：能运行、能验证、能发现问题，比先写漂亮描述更重要。
- **少一点过程噪音**：频繁刷新、自动同步、成功提示这些东西，默认应该安静。
- **重视安装态**：桌面应用不能只看 dev server，打包后的 `.app` / `.dmg` 也要验证。
- **把经验沉淀下来**：能复用的命令、排查路径、发布检查项，都值得留下来。
